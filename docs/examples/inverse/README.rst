Inverse Problems
================

These examples fit bounded parameters to measured or synthetic observations.
They progress from a small analytic model to a unit-aware PyMieSim scattering
calculation. The optimizer is deterministic, derivative-free, and intended for
a small number of parameters.

Fits using isolated-particle scattering inherit the non-interacting
approximation of their forward model. Refer to PackLab when particle
correlations or dependent scattering need to be represented.
