PyMieSim documentation#

Calculate light scattering by spheres, core-shell spheres, and infinite cylinders. Build a single-particle model, sweep experimental parameters, or fit physical parameters to measured data with explicit units.

Choose your starting point#

  • Have a calculation in mind? Use Choose an interface.

  • Installation failing? Check Compatibility matrix and Troubleshooting.

  • Preparing a reproducible study? See Reproducible studies and Performance and scaling.

PyMieSim models isolated-particle scattering. Particle-size averaging assumes independent scattering; it does not add interactions between particles. See Particle-size distributions: independent scattering for the averaging assumptions.
