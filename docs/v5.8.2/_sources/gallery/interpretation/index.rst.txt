Interpreting scattering results
===============================

These examples connect computed observables to common scattering decisions.
They separate scattering from absorption in an extinction spectrum, show how
particle size changes the angular phase function, and diagnose a sphere fit
across multiple wavelengths. Numerical convergence and isolated-particle model
assumptions remain part of each interpretation.
