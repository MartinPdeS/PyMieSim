.. _examples_gallery:

Coding examples
===============

Each gallery contains runnable Python scripts and their outputs. Start with a
small example, then follow the interpretation gallery to connect numerical
results to physical conclusions. Measure requests use ``Measure`` members;
result names and table column names remain strings such as ``"Qsca"``.
